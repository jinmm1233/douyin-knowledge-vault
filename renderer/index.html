使用说明书

          

            📖 这个软件是干什么的？
            

              
这是一个抖音收藏 → 个人知识库自动化工具。你收藏的抖音视频会自动：下载 → 本地语音转文字（Whisper，无需联网）→ 交给 AI 提炼知识 → 自动分类归档到 Obsidian 知识库 → 生成笔记、观点印证、知识卡片与日报。

              
全程在你自己的电脑上运行，笔记和数据都存在本地知识库文件夹里，不依赖别人。

            

          

          

            ✨ 项目亮点
            

              
    
                
  • 智能识别视频类型：自动分辨广告、短剧、搞笑、音乐（唱歌/演奏）、舞蹈、才艺表演、纯画面（萌宠/风景大片）、吃播等娱乐类视频，直接跳过不写笔记，不浪费 token、不占用空间，也不会反复重试；美食制作教程、探店测评等有信息量的内容正常整理。
    • 
                
  • 自动分类整理：AI 按内容自动归档成「大分类 → 主题 → 具体子类」三级结构，同类视频自动聚在一起，无需手工整理。
    • 
                
  • 观点印证文档：同一个观点在多个视频里互相印证或补充时，会自动汇总进分类下置顶的「00-共识观点」文档——多来源互相验证的信息更可信，一眼看到重点。
    • 
                
  • 蒸馏成技能包：把某个子类的笔记用仓颉七阶段流水线"蒸馏"成可复用的技能文档，之后还能直接对蒸馏结果 AI 提问。
    • 
                
  • 知识卡片：按大分类提炼「互相印证的观点 + 单视频知识」，生成思维导图、印证网络、速查表，快速掌握一个主题。
    • 
                
  • 全自动增量更新：每天定时只处理「昨天新收藏 + 昨天失败」的视频，不重复处理历史内容，今天收藏的明天自动整理。
    • 
                
  • 完全本地：笔记写进本机 Obsidian 知识库，转录用本地 Whisper（不联网、免费），AI 提取才按需调用你的 API Key。
    • 
              

            

          

          

            🚀 快速上手（基本流程）
            

              
    
                
  1. 配置 API Key：在下方「AI 接口配置」里填 Base URL、Key 和模型名（任意 OpenAI 兼容接口，DeepSeek/Kimi/OpenAI 都行），然后点设置页右上角「确认修改 · 应用全部设置」。
    2. 
                
  2. 登录抖音：在「抖音账号」面板点「打开抖音扫码登录」，用手机扫码。
    3. 
                
  3. 开始处理收藏：切到「总览」页，点「开始处理收藏」。第一次会让你选择起始日期——只处理某天之后新增收藏的视频，也可以选「处理所有收藏视频」。
    4. 
                
  4. 等待整理：软件会逐条下载、转录、提炼并写笔记，进度在总览进度条和流水线面板实时显示。
    5. 
                
  5. 看结果：处理完去「知识库」页看笔记（按大分类 → 父类 → 子类归档）；去「知识卡片」页看 AI 提炼的印证观点、思维导图、速查表。
    6. 
                
  6. 每日自动更新：在设置里配好「定时任务」，每天早上自动处理昨天新收藏 + 昨天失败的视频（需电脑开机；较早历史收藏已在归档时跳过，不重复处理）。
    7. 
              

            

          

          

            🔑 一定要用 API Key 吗？
            

              
要的。视频转录后的「知识提取」「观点印证」「知识卡片」「AI 问答」都需要调用云端大模型，因此必须配置一个 OpenAI 兼容接口的 API Key：

              
    
                
  • 在「AI 接口配置」填 Base URL（如 DeepSeek 的 https://api.deepseek.com/v1）、API Key（在对应平台官网申请）、模型名（如 deepseek-chat）。
    • 
                
  • Key 只存在你自己电脑的设置文件里，不会上传到别处。
    • 
                
  • 转录本身是本地免费的（Whisper），不需要网络；只有 AI 提炼那一步消耗 token，按各平台自己的价格计费。
    • 
              

            

          

          

            🔒 收藏是怎么获取的？有风控风险吗？
            

              
原理：用你自己登录的抖音账号，通过网页版接口直接读取你的「我的收藏」列表（只读你自己的数据，不碰别人的内容），拿到每个视频的播放地址后下载到本地处理。整个过程是 API 直连，不是模拟浏览器点击，也不会代替你发布、点赞、评论任何内容。

              
风控说明：抖音对接口调用有频率限制，任何第三方工具都存在被限流的理论风险。实际会遇到的情况和处理方式：

              
    
                
  • 拉取太频繁会被临时限流：接口会提示稍后再试，等几分钟自动恢复，不会永久封禁。
    • 
                
  • 播放地址约 2 小时过期：过期后下载会报 403，软件已内置「地址自动保鲜」，批量处理时定时重新刷新。
    • 
                
  • 登录态可能失效：失效后到设置页重新扫码即可，无需重装任何东西。
    • 
                
  • 软件默认增量拉取：每天只拉新增收藏，不反复全量请求，频率很低。
    • 
              

              
建议：正常个人使用风险很低；避免短时间反复全量拉取、遇到限流提示就停一会儿。如担心账号安全，可先用小号或减少使用频率观察。

    • 
                
  • 语义检索：不翻目录，直接输入关键词全局搜索所有笔记，命中内容高亮显示。
    • 
                
  • 流水线：查看本次同步的运行进度（处理率）与实时日志，随时掌握处理状态。
    • 
                
  • 我的技能：管理已蒸馏好的技能包，查看技能详情，选择技能后配合 AI 问答使用。
    • 
                
  • 知识卡片：AI 按大分类提炼「互相印证的观点 + 单视频知识」，生成思维导图、印证网络和速查表；视频不足 50 条的分类自动跳过。
    • 
                
  • 止损看板：集中查看处理失败与自动跳过（广告/短剧/搞笑等）的视频清单，快速定位问题。
    • 
                
  • 知识蒸馏与 AI 问答：把某个子类的笔记用仓颉七阶段流水线"蒸馏"成可复用的技能包；选定技能后可以直接向 AI 提问。
    • 
                
  • 设置：项目路径、AI 接口、抖音登录、皮肤、定时任务、每周知识周报都在这里。

            ❓ 常见问题
            

              
    
                
  • 抖音登录失效了？到「抖音账号」点「打开抖音扫码登录」重新扫码即可。
    • 
                
  • 下载视频报 403？视频地址有时效（约 2 小时），自动刷新失败时重新登录抖音后重跑即可。
    • 
                
  • 广告/短剧/搞笑/音乐（唱歌、演奏）/舞蹈/才艺表演/纯画面（萌宠、风景大片）/吃播会被自动识别并跳过，不写笔记、不重复处理；美食制作教程、探店测评等有信息量的内容会正常整理。
    • 
                
  • 处理完的视频会占空间吗？不会，转录并生成笔记后，软件会立即删除下载的视频文件。
    • 
                
  • 定时任务没跑？定时任务需要电脑开机且处于登录状态；错过的时间会在下次开机后自动补跑。
    • 
                
  • 想改接口/换模型？直接在「AI 接口配置」改后保存，之后所有 AI 功能（含定时任务）都会用新配置。
    • 
                
  • 起始日期到底按什么时间？抖音接口不提供"你收藏这个视频的时刻"。本软件以视频的发布时间作为判断依据：起始日期筛选的是视频发布时间在该日期之后的收藏，更早的永久跳过（可在设置里改日期或勾选「处理所有收藏视频」恢复）。
    • 
                
  • 起始日期改了会怎样？设置新日期会恢复旧标记并按新日期重新打标；勾选「处理所有收藏视频」则清空日期限制，全部收藏重新进入处理。
    •
